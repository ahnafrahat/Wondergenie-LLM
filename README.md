# WanderGenie LLM

WanderGenie LLM is an innovative iOS application that leverages artificial intelligence to create personalized travel itineraries based on user preferences. This app helps travelers plan their perfect trip by considering their interests, budget, and travel style.

## Features

- 🤖 AI-Powered Itinerary Generation
- 🎯 Personalized Travel Planning
- 💰 Budget Consideration
- 🏨 Accommodation Suggestions
- 🍽️ Restaurant Recommendations
- 🎡 Activity Planning
- 📍 Location-Based Services

## Requirements

- iOS 13.0+
- Xcode 12.0+
- Swift 5.0+

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ahnafrahat/Wondergenie-LLM.git
```

2. Open the project in Xcode:
```bash
cd WanderGenie_LLM
open WanderGenie_LLM.xcodeproj
```

3. Build and run the project in Xcode

## Usage

1. Launch the app
2. Enter your travel preferences including:
   - Destination
   - Travel dates
   - Budget
   - Interests
   - Travel style
3. Let the AI generate your personalized itinerary
4. Review and customize the suggested plan
5. Save and share your itinerary
